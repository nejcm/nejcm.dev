Unified LLM Interface Specification is a CLI for maintaining agent configuration in one canonical tree. It generates and installs native files for Claude Code, OpenCode, Codex, Cursor, ForgeCode, Antigravity, and Hermes Agent, with project and global modes.

The project is under active development. Generated configuration can be inspected before installation, and existing configuration can be backed up when installing.

[Read the README](https://github.com/nejcm/ulis#readme).
