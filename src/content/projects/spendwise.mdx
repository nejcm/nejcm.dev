A free personal finance app built with Expo and React Native. Core financial data stays on-device, with support for accounts, budgets, transactions, recurring bills, spending statistics, CSV import and export, and JSON backup and restore.

Optional AI chat and receipt scanning use your own provider key. The app also supports device authentication for an optional app lock.
